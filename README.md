# StudApp
Суперапп для студентов/преподавателей/администрации вузов, лицеев и колледжей.

Стек backend: **Go + PostgreSQL**.

## Документация

[Пользовательские сервисы и логика экранов](docs/ARCHITECTURE.md) — общий обзор, C4-диаграммы и логика работы.

## Организация проекта

На первом этапе используем архитектуру модульного монолита: бэкенд запускается и развёртывается как единое приложение, а бизнес-сервисы имеют собственные зоны ответственности и взаимодействуют через явно определённые контракты.

Границы бизнес-логики задают сервисы: `account`, `administration`, `schedule`, `materials`, `assignments`, `submissions`, `review`, `results` и `notifications`. Код разделён по техническим слоям, а внутри каждого слоя используются эти же имена сервисов. Интерфейсы зависимостей объявляются рядом с потребителями.
